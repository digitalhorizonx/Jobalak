# Jobalak

AI-assisted job discovery for the Egyptian market.

## Current MVP
- Arabic-first landing page
- CV file selection UI
- Target-country selection (max 5)
- Email capture
- Visa sponsorship preference
- 69 EGP CTA placeholder
- Hostinger-compatible Next.js structure

## Planned integrations
- CV parsing and structured candidate profiles
- Job indexing from public ATS/company career sources
- Match scoring and verification
- Paymob mobile-wallet checkout
- Email delivery pipeline

## Run locally
```bash
npm install
npm run dev
```

## Production
```bash
npm install
npm run build
npm run start
```
